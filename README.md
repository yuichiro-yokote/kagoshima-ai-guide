# かごしまAIガイド

鹿児島を訪れる観光客向けに、AIとのチャットと地図を組み合わせた観光ガイドのWebアプリです。

2026年6月の学内ハッカソンで、4人のチームで作りました。私はAIによるおすすめの部分と、各メンバーが作った機能（口コミの表示、経由地、降灰シミュレーション、スマホ向けの画面、観光データの整形）を1つのアプリにまとめる部分を担当しました。

- 公開中のアプリ: https://kagoshima-ai-guide.vercel.app/
- 発表: 2026年6月30日（学内ハッカソン）

## なぜ作ったか

ハッカソンでは「鹿児島の地域課題を解決するサービス」を作ることになり、チームで出した案の中から、A地点からB地点へ移動する途中で寄れるお店や施設を薦めるというアイデアを選びました。観光情報のサイトは場所ごとにまとまっていて、移動の流れに沿って「この先に何があるか」「残りの時間でどこに寄れるか」を探すのには向いていないと考えたからです。

そこで、行き先までの道のりと空いている時間を伝えると、その途中で寄れる場所をAIが選んで地図に出すアプリにしました。鹿児島ならではの桜島の降灰も、風向きから地図に表示できるようにしています。

## できること

チャット、経路検索、降灰シミュレーションの3つの使い方があります。

- チャット: 鹿児島の観光・交通・グルメなどを質問すると、AIが答え、話に出た場所を地図にピンで示します。鹿児島市のオープンデータにある観光スポットをAIに渡しているので、データにある場所を優先して答えます。
- 経路検索: 出発地・経由地・目的地を入れると道のりを表示し、沿道の観光地・飲食店・トイレ・駐車場などを並べます。空いている時間（10分から1時間以上）を選ぶと、その時間で寄れる場所をAIが選びます。口コミの評価で並べ替えたり、気になる場所を経由地に足したりできます。
- 降灰シミュレーション: 現在の風向き・風速から、桜島の灰が降りそうな範囲を地図に扇形で表示します。

細かい仕様は [docs/features.md](docs/features.md) にまとめています。

## 仕組み

```
ブラウザ（Next.js の画面、Leaflet の地図）
  |
  +-- /api/chat ................ Claude API にスポット情報と質問を渡して回答を得る
  +-- /api/geocode ............. 地名を緯度経度に変換する（Photon、だめなら Nominatim）
  +-- /api/route ............... 道のりを求める（OSRM）
  +-- /api/spots-along-route ... 道のりの周りの場所を探す（Overpass API、Google Places API）
  +-- /api/spot-info ........... 口コミの評価と写真を取る（Google Places API）
  +-- /api/ashfall ............. 風向き・風速を取る（Open-Meteo）
```

道のりを5つの区間に分けて、区間ごとに場所を選んでいます。出発地の近くだけに候補が偏らないようにするためです。

| 要素 | 使ったもの |
|---|---|
| 画面 | Next.js、TypeScript、Tailwind CSS |
| AI | Claude API（Haiku 4.5）、Vercel AI SDK |
| 地図 | Leaflet、OpenStreetMap |
| 道のり | OSRM |
| 地名の検索 | Photon、Nominatim |
| 周りの場所 | Overpass API、Google Places API |
| 天気 | Open-Meteo |
| 観光データ | 鹿児島市オープンデータ（BODIK ODCS） |
| 公開 | Vercel |

## 作っていて分かったこと

- 最初はAIが「観光案内所でお尋ねください」のように具体的な場所を挙げなかったり、指定した地域の外の場所を薦めたりしました。必ず具体的な名前を挙げること、指定した地域の中から選ぶことをAIへの指示に加えました。
- データにない地域を聞かれると、AIが実在しない店名を作ってしまうことがありました。その場合はGoogle Places APIで周りの実在する店を調べてAIに渡し、地図とカードには評価か写真を確かめられた場所だけを出すようにしました。
- データは鹿児島市のオープンデータから始め、県内全体の観光地123件と飲食店を足していきました。
- 地図を引いて表示するとピンが多すぎて読めなくなるので、拡大率に合わせて表示する数を変えています。

## 動かし方

Node.js 20以上が必要です。Claude API と Google Places API のキーを自分で用意してください。

```bash
git clone https://github.com/yuichiro-yokote/kagoshima-ai-guide.git
cd kagoshima-ai-guide
npm install
```

`.env.local` を作り、キーを書きます。このファイルはGitに入れないでください（`.gitignore` 済みです）。

```
ANTHROPIC_API_KEY=Claude API のキー
GOOGLE_PLACES_API_KEY=Google Places API のキー
```

```bash
npm run dev
```

http://localhost:3000 を開きます。Dockerを使う場合は `docker compose up --build` でも起動できます。

## ファイル構成

| 場所 | 内容 |
|---|---|
| `src/app/page.tsx` | 画面（チャット、経路検索、降灰の切り替え） |
| `src/app/api/` | サーバー側の処理（上の図の6つ） |
| `src/components/` | 地図と地名の入力欄 |
| `src/data/` | 観光スポットと飲食店のデータ（鹿児島市オープンデータを整形したもの） |
| `docs/features.md` | 機能の細かい仕様 |

## 注意

- ハッカソンのために作ったもので、表示する情報の正しさは保証していません。営業時間などは公式の情報を確認してください。
- 降灰の表示は風向きから描いた目安で、気象庁の降灰予報ではありません。
