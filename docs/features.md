# 機能の詳細

READMEの「できること」の細かい仕様です。

## チャット

- 鹿児島を中心に、観光・施設・交通・グルメ・歴史など旅行全般の質問に答えます。
- 回答に出た場所を地図にピンで表示し、回答の中に写真つきのカードを出します。カードを押すと、地図がその場所へ移動して詳細を開きます。
- 観光スポットと飲食店のデータ（`src/data/`）をAIに渡しています。データにない地域を聞かれたときは、地名を緯度経度に変えてGoogle Places APIで周りの場所を調べ、その結果をAIに渡します。
- 地図とカードに出すのは、Google Places APIで評価か写真を確かめられた場所だけです。

## 経路検索

- 出発地・経由地（3件まで）・目的地を入れると、道のりと沿道の場所を表示します。
- 場所の種類は、観光・展望・飲食・買い物・トイレ・駐車場です。
- 口コミの評価（星の数）と件数をGoogle Places APIから取って表示します。左の一覧は写真・名前・評価のカードで、評価順・口コミ数順の並べ替えと、星4.0以上だけを出す絞り込みができます。
- カードの「＋経由」で、その場所を経由地に足せます。
- 空いている時間（10分、30分、1時間、1時間以上）を選ぶと、AIがその時間で寄れる場所を選びます。
- 道のりを5つの区間に分け、区間ごとに場所を選びます。
- 地図の拡大率に合わせて、表示する場所の数を変えます。

## 降灰シミュレーション

- 桜島から灰が降りそうな範囲を、地図に扇形で表示します。
- 風向き・風速はOpen-Meteo APIからその時点の値を取ります。
- チェックボックスで表示を切り替えます。
